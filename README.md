# Task 1: Data Cleaning and Preprocessing

## 📌 Project Overview

This project focuses on cleaning and preprocessing the Customer Personality Analysis dataset using Python and Pandas.

The objective was to identify and handle missing values, remove duplicate records, standardize text values, convert date formats, clean column names, and verify appropriate data types.

## 🎯 Objective

To transform a raw dataset into a clean and consistent dataset that can be used for further data analysis and machine learning tasks.

## 🛠️ Tools Used

- Python
- Pandas
- NumPy
- Google Colab
- Kaggle Dataset

## 📊 Dataset

**Dataset:** Customer Personality Analysis

The dataset contains customer demographic information, purchasing behavior, campaign responses, and other customer-related attributes.

## 🧹 Data Cleaning Steps

The following preprocessing steps were performed:

1. Loaded the raw dataset using Pandas.
2. Inspected the dataset structure and dimensions.
3. Checked for missing values.
4. Handled missing values in the Income column using the median.
5. Checked for duplicate records.
6. Removed duplicate rows.
7. Standardized column names to lowercase with underscores.
8. Cleaned categorical text values by removing unnecessary spaces.
9. Converted the customer date column to datetime format.
10. Checked and corrected numerical data types.
11. Performed final validation of missing values and duplicates.
12. Exported the cleaned dataset as a CSV file.
